# 内置控制接入证据

目标：用户提供的 NEW STATE 0.9.98(804)，主程序 SHA-256 `cf59f3663bba56b035024e71d814ffceecf86d5d99bd90873c2fd82372e3a0c7`。所有二进制检查在 GitHub 托管 macOS 进行。本文仅整理派生文本，不含设备原始日志或游戏二进制。

人物加速：CharacterMovement 的属性表确认 MaxWalkSpeed 为 `+0x6dc`，MaxWalkSpeedCrouched 为 `+0x420`。原始基础速度函数 `0x505566c` 按移动状态及蹲伏状态读取这些字段。模块使用对象代数、世界和控制角色关系检查后在游戏任务队列修改；请求范围1–3倍，保存原值，验证读回，停止时只恢复仍由模块持有的值。游戏改值会停止该请求。此证据不证明实际净移速或服务器接受倍速。

载具：沿原始 GetVehiclePawn 的 `0x22d23e4 → 0x3189170 → 0x4ede944` 关系读取当前乘坐载具。PrimitiveComponent 属性类型函数 `0x59a0718` 的实际单例槽为 `0x80ae820`，不沿用外置边界显示使用的其他类型槽。接口原始调用点确认 SetEnableGravity 使用虚表 `+0x818`，IsGravityEnabled 使用 `+0x820`，SetPhysicsLinearVelocity 使用 `+0x690`。GetPhysicsLinearVelocity 的原生目标为 `0x5517194`；参数及三浮点向量 ABI 在原始 exec thunk 中核对。模块修改重力和垂直速度，保留水平速度；关闭后恢复有效组件的原始重力，不恢复陈旧速度。真实物理效果及网络校正仍未设备验证。

无敌与减伤：固定输入中 `GodMode` 的 exec 包装 `0x3740f70` 调用 `0x1ca7564`；`DamageScale` 包装 `0x3743a4c` 调用 `0x1ca66ec`，这两个目标在已检查上下文中都是一条 `ret`。另有 `Invincible` 命中教程机器人状态和观察者轮廓枚举；Actor 的 bCanBeDamaged 位操作不证明远端伤害结算改变。上述发现不能证明游戏不存在其他路径，但这些入口不足以实现请求的对局无敌、减伤。本候选版未实现、未开放这两个功能。

未编入自瞄、压枪、旧警告补丁或旧脉冲时间加速模块。原外置显示 App 保留独立；内置控制使用游戏自身 UIKit 窗口，不依赖跨应用输入接收器。
