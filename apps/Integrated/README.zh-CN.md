# FanProMAX 内置移动核查

当前源码为 `integrated-i3.2-review`；最后已发布的手机候选仍是 i3.1。本轮不发布新手机安装包。目标设备为 iPhone 15 Pro Max、iOS 17.0、TrollStore，原始游戏为 0.9.98 (804)。

用户的 i3.1 数据已经否定实际 3 倍速度：可比稳定窗口约为正常 6.4 m/s、选定 3 倍时 8 m/s。车辆能升高但很快被拉回。人物飞天、无敌、减伤均未实现；自瞄和压枪继续排除。不要把字段写入、调用次数或构建通过当作目标已完成。

## 本轮修改

飞车每次操作检查物理组件身份及重力是否仍保持预期，发送速度指令后回读三个速度分量。回读不匹配会报告失败并尝试恢复仍归本模块持有的重力状态。不会恢复旧速度，也不会覆盖游戏自行改变的重力。回读只证明当时本地物理速度数值一致，不证明持续飞行或服务器接受。

每个完整的两秒移动窗口保留不可变的 `end_sample_context`，包括窗口结束时的步行/蹲行字段、原生最终速度以及几个待判定是否正在生效的限速字段。上车后的当前上下文不会覆盖这些历史信息。这是窗口末尾的一次观测，不是窗口内的最小值、最大值或平均值。仍保留最多 90 个完整窗口，不导出世界坐标。

## 构建与发布

推送默认只执行 GitHub-hosted macOS 上的单元测试、原始二进制特征核对、模块编译/签名检查和 UIKit 界面检查。模块二进制不作为本轮测试包发布；上传检查报告。IPA 打包、暂存及发布均要求显式 `workflow_dispatch` 且 `publish_candidate=true`，默认关闭。发布流程继续检查相同提交的构建、界面及包摘要。

本轮不要求用户再重复安装或重做已有测试。后续运行时核查必须有明确目标，不能仅为了重复证明“字段写入了”。离线分析与尚未解决的问题见 [motion-offline-review.md](../../analysis/motion-offline-review.md)。
