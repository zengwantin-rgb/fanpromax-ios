# FanProMAX 内置控制试验 i1

用户已选择将功能内置到游戏IPA，目标为15PM／iOS17.0／TrollStore。自瞄和压枪继续排除。

本模块和原外置显示App独立。内置按钮通过游戏自己的UIKit窗口响应轻点和拖动；外置显示和雷达暂时仍由原App提供，没有移入任何旧自瞄/压枪或警告处理模块。

已编写人物1–3倍速度字段试验和当前乘坐载具的飞车试验（下降、悬停、上升）。开关每次启动默认关闭。人物速度修改步行/蹲行上限，写入后读回确认，发生身份失效、游戏改值或写入失败时停止。载具仅通过已核对的物理接口改变重力和垂直速度；保留水平速度。关闭后恢复仍有效组件的原重力状态，不恢复陈旧速度。实际净速度、网络校正和飞车效果须手机对局确认，字段倍数不等于已达到的实际倍速。

无敌与减伤尚未实现。分析找到的受伤标记位于AActor，相关Invincible和DamageReduction名字并非已经验证的本地玩家减伤入口；不提供伪装成功的无敌/减伤开关，也不通过血量显示变化宣称对局无敌。

仅针对0.9.98(804)且主程序UUID/指纹匹配的原输入。UE任务类和函数地址/类型均核对后才提交操作。参数修改仅在验证过的游戏任务回调中进行，角色/组件复用代数、世界和所属关系变化后不向旧对象写入。输入IPA只在GitHub托管macOS下载、检查和打包；工作服务器只编辑源码和查看文本报告。

安装测试：先停止旧外置悬浮层，通过TrollStore安装候选游戏IPA；不先删除原游戏。先确认原生游戏可启动，按钮F可轻点/拖动。再分别测试人物1.5倍/2倍和乘车后的悬停/上升/下降。每项测试后关闭开关确认恢复；导出Documents/FanProMAX/integrated-status.json。未通过设备测试之前不标记为实战有效。
