# FanProMAX 内置 i3：驾驶位识别与速度实测

[下载模块与完整 IPA](https://github.com/zengwantin-rgb/fanpromax-ios/releases/tag/integrated-f23779df4343)。编译源码 `f23779df43434ddcdc912cc5df971e1e8c5a6060`；[云端构建、回归、UIKit与发布核对](https://github.com/zengwantin-rgb/fanpromax-ios/actions/runs/42718652283)全部通过。目标为15PM／iOS17.0／TrollStore，固定游戏0.9.98(804)。源码、函数指纹或ABI不匹配时不启用修改。

用户确认i2在存活步行中识别和字段保持正常，但加速没有体感变化；驾驶位中角色缺失，飞车调用为0。字段倍率不等于实际净移速，alive_readable=false不代表已确认死亡。

飞车：i3独立读取本地控制器直接持有的载具，不再要求存在步行人物；保留人物乘坐关联路径。修改前校验本地归属、世界、车辆/物理组件代数、组件类型及所有者。支持下降、悬停、上升，保留水平速度；关闭时恢复仍有效组件的原重力，不恢复陈旧速度。实际飞行效果待手机确认。诊断新增flight_target_ready、flight_target_reason、flight_target_route。

人物加速：仍为步行/蹲行速度字段1–3倍试验，实际无明显变化的原因尚未确定。i3记录原生最终速度上限、本地水平速度，以及2秒窗口的净位移速度和路径速度；这些读数不证明服务器接受或实际达到所选倍数。窗口包含停步，同一人物/倍率下连续采样；身份变化、倍率变化和较长采样中断会重置窗口。日志不输出世界坐标。

自瞄和压枪未编入；无敌、减伤尚未实现。外置显示App保持独立。每次启动默认关闭参数修改。只在经验证的游戏任务队列中操作，临时身份不可读时保留原值记录，避免恢复后重复累乘。

测试步骤：

1. 自行注入时替换旧FanProIntegrated.dylib并彻底结束游戏后重开。完整IPA已经包含本版模块，无需重复注入。
2. 确认日志version为integrated-i3。速度关闭时在平地向前直走约5秒，导出一份integrated-status.json；打开3倍后在相同路段、相同操作方式直走约5秒，再导出一份。两个状态文件共同用于比较。
3. 坐在驾驶位，开启飞车后选择“上升”。默认“悬停”不主动增加高度。再测试下降、关闭及下车恢复，并导出状态。
